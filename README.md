# DevPulse API

Express + TypeScript API implementing Users and Issues with JWT auth.

Quick start

1. Copy `.env.example` to `.env` and set values (do NOT commit `.env`).
2. Install deps:

```bash
npm install
```

3. Run in dev:

```bash
npm run dev
```

Vercel

Set environment variables in Vercel dashboard matching `.env` keys. The `vercel.json` file is included.
